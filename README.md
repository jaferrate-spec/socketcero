# SocketCero

Socket cero es una tienda de hardware (componentes para PC) de origen chileno, este programa es su software de administración de stock y contacto para proovedores de componentes.

## Stack tecnologico

- Java (JDK 27)
- JavaFX
- JDBC
- MySQL

### Información adicional
Este repositorio fue creado con el fin de presentar el Examen Transversa de Desarrollo Orientado a Objetos, "Socket Cero" no existe y tampoco lo son los datos utilizados (RUTs, razones sociales, etc)
